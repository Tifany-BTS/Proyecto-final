Agrega una nueva tarjeta de testimonio en la sección de testimonios
de la página que indique el usuario, respetando la estructura, contenido
y patrón visual existente.

Reglas:
- Localiza primero la sección de testimonios existente antes de realizar
  cualquier cambio
- Revisa las tarjetas de testimonio actuales y utiliza la misma estructura
  HTML y las mismas clases CSS
- Agrega el nuevo testimonio dentro del mismo contenedor donde se encuentran
  las demás tarjetas
- Solicita o utiliza los datos proporcionados por el usuario para el
  testimonio: nombre de la persona, texto del testimonio y cualquier otro
  dato que utilicen las tarjetas existentes
- No inventes información que el usuario no haya proporcionado
- Mantén la misma jerarquía de etiquetas HTML que utilizan los testimonios
  existentes
- Conserva las clases CSS existentes y reutilízalas siempre que sea posible
- No crees nuevos estilos CSS si el diseño actual ya permite representar
  correctamente el nuevo testimonio
- Mantén el patrón visual existente: espaciado, tipografía, bordes,
  distribución y comportamiento responsive
- Si las tarjetas utilizan elementos semánticos como `article`, `blockquote`
  o `cite`, conserva el mismo patrón
- Si existen imágenes o avatares, utiliza únicamente la imagen indicada
  por el usuario y agrega un atributo `alt` descriptivo
- No modifiques ni elimines los testimonios existentes
- No cambies textos, navegación, colores ni otras secciones de la página
- No modifiques archivos que no sean necesarios para agregar el testimonio
- Mantén la accesibilidad y responsividad existentes
- Antes de finalizar, verifica que la nueva tarjeta se comporte correctamente
  tanto en dispositivos móviles como en escritorio
- Al terminar, informa brevemente qué archivo o archivos fueron modificados
  y dónde se agregó el nuevo testimonio
