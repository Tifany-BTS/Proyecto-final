# CU-03: Asesor de Combinación y Paleta de Colores

## Descripción
Permite a la Visitante y Clienta seleccionar un color base o una prenda específica en una sección dedicada para recibir sugerencias automáticas de paletas de color y prendas complementarias de la tienda.

## Actores
- Visitante
- Clienta

## Precondiciones
- La sección interactiva de colores debe estar accesible desde la navegación principal.

## Flujo Principal (Camino Feliz)
1. La usuaria ingresa a la sección 'Combinador / Asesor de Colores'.
2. La usuaria selecciona un color base o elige una prenda del catálogo.
3. El sistema procesa la selección y muestra la paleta armónica sugerida (análoga, complementaria o neutra).
4. El sistema presenta recomendaciones de prendas disponibles en la tienda que hacen match con esa combinación.
5. La usuaria puede hacer clic en cualquiera de las prendas recomendadas para ver su detalle (CU-02).

## Flujos Alternativos / Excepciones
- **Selección no válida o sin recomendaciones directas:** Si se selecciona una combinación poco común, el sistema sugiere una paleta neutra predeterminada.

## Postcondiciones
- La usuaria obtiene sugerencias estéticas de vestuario y enlaces a los productos recomendados.
