# CU-03: Asesor de Color / Personalización

- **Actor Principal:** Usuario / Cliente
- **Objetivo:** Recibir recomendaciones personalizadas de tonos y paletas según preferencias o tono de piel/estilo.
- **Iniciador:** El usuario selecciona la opción "Asesor de Color" desde el menú o la ficha de producto.
- **Condiciones Previas:** El catálogo contiene productos categorizados por paleta cromática.

## Pasos del Recorrido Principal

1. El usuario ingresa a la sección del Asesor de Color.
2. El sistema presenta un cuestionario o selector de preferencias cromáticas/estilo.
3. El usuario completa las opciones requeridas.
4. El sistema analiza las respuestas y muestra una lista de productos recomendados afines.



## Alternativas y Excepciones

- **A1 (Sin coincidencias exactas):** Si las preferencias no arrojan una coincidencia perfecta, el sistema sugiere la paleta general más cercana.



## Criterios de Aceptación

- CA-01: El usuario puede completar la interacción de selección.
- CA-02: El sistema devuelve productos filtrados acordes a la opción elegida.
