# CU-01: Explorar Catálogo y Filtrar Productos

## Descripción
Permite a la Visitante y Clienta navegar por la lista de prendas de vestir disponibles en Purple Bloom, aplicando filtros por categoría, talla o color para encontrar productos de su interés.

## Actores
- Visitante
- Clienta

## Precondiciones
- La aplicación debe estar cargada correctamente en el navegador.
- La base de datos de productos debe estar disponible.

## Flujo Principal (Camino Feliz)
1. La usuaria ingresa a la sección principal de catálogo de Purple Bloom.
2. El sistema muestra una grilla de productos con imagen, nombre, precio y disponibilidad.
3. La usuaria selecciona uno o varios filtros (categoría, talla, rango de precio).
4. El sistema actualiza la lista mostrando únicamente los productos que coinciden con el criterio.
5. La usuaria hace clic en una tarjeta de producto para ver sus detalles.

## Flujos Alternativos / Excepciones
- **Sin resultados:** Si ningún producto coincide con los filtros seleccionados, el sistema muestra el mensaje: 'No se encontraron prendas con los filtros elegidos' y ofrece un botón para limpiar filtros.

## Postcondiciones
- La usuaria visualiza el catálogo filtrado o es redirigida al detalle del producto seleccionado (CU-02).
