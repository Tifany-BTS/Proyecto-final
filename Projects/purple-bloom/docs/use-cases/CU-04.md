# CU-04: Gestionar Carrito de Compras

## Descripción
Permite a la Clienta revisar las prendas agregadas al carrito, ajustar cantidades, eliminar productos y visualizar el desglose de precios (subtotal, impuestos y total estimado).

## Actores
- Clienta

## Precondiciones
- La Clienta debe haber seleccionado al menos una prenda para agregar al carrito desde la vista de detalle (CU-02) o el combinador de colores (CU-03).

## Flujo Principal (Camino Feliz)
1. La Clienta hace clic en el ícono del carrito de compras.
2. El sistema muestra el listado de prendas agregadas con sus detalles (imagen, nombre, talla, color, precio unitario y cantidad).
3. La Clienta modifica la cantidad de un producto o elimina una prenda de la lista.
4. El sistema recalcula automáticamente el subtotal, impuestos y total de la compra.
5. La Clienta presiona el botón 'Proceder al Pago' para iniciar la simulación del pedido.

## Flujos Alternativos / Excepciones
- **Carrito vacío:** Si la Clienta elimina todos los productos del carrito, el sistema muestra el mensaje 'Tu carrito está vacío' y ofrece un botón para volver al catálogo (CU-01).

## Postcondiciones
- El carrito se actualiza correctamente y la Clienta queda lista para avanzar al proceso de checkout (CU-05).
