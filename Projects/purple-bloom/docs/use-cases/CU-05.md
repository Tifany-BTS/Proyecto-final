# CU-05: Simular Pago y Confirmación de Pedido

## Descripción
Permite a la Clienta completar el proceso de compra simulado ingresando datos de envío ficticios, seleccionando un método de pago de prueba y obteniendo la confirmación del pedido generado.

## Actores
- Clienta

## Precondiciones
- La Clienta debe tener al menos una prenda en el carrito de compras (CU-04).

## Flujo Principal (Camino Feliz)
1. La Clienta selecciona la opción 'Proceder al Pago' desde el carrito.
2. El sistema despliega el formulario de envío (dirección, ciudad, teléfono simulados).
3. La Clienta selecciona un método de pago simulado (tarjeta de prueba, transferencia ficticia) y confirma la transacción.
4. El sistema procesa la solicitud, genera un número de pedido único y limpia el carrito de compras.
5. El sistema muestra la pantalla de confirmación con el resumen completo del pedido.

## Flujos Alternativos / Excepciones
- **Campos incompletos:** Si la Clienta omite ingresar un dato obligatorio en el formulario, el sistema resalta los campos faltantes y no permite procesar el pago hasta corregirlos.

## Postcondiciones
- El pedido queda registrado de forma simulada y la Clienta recibe el comprobante en pantalla.
